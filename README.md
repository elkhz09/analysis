## Projects

### [COE Price Dynamics — Singapore](coe-price-dynamics/)
Time-series econometric analysis of Singapore's COE premium system using 20+ years of LTA data.
Applies ADF stationarity tests, Granger causality, and lagged correlation analysis.

**Skills:** time-series analysis · Granger causality · ADF testing · econometrics · Python

### [Recipe Traffic Prediction](datacamp-capstone/)
Binary classification project predicting high-traffic recipes for a digital food platform.
Logistic Regression achieved 87% precision against an 80% business target.
Completed as the DataCamp Data Scientist Professional certification capstone.

**Skills:** classification · feature engineering · model selection · business framing · Python
